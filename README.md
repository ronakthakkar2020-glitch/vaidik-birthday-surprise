# Vaidik Birthday Surprise

A shareable, responsive birthday memory website for Vaidik.

## Add the photos

The website is ready for the 14 memories. Add the original image files to the `images/` folder using these exact names:

`01.jpg`, `02.jpg`, `03.jpg`, `04.jpg`, `05.jpg`, `06.jpg`, `07.jpg`, `08.jpg`, `09.jpg`, `10.jpg`, `11.jpg`, `12.jpg`, `13.jpg`, `14.jpg`

Image `01.jpg` is displayed as the large featured memory. All 14 images can be clicked to open in the full-screen viewer, with previous/next navigation.

The image previews in chat are not available to repository tools as downloadable files, so the original files need to be uploaded to this folder before publishing.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub will provide the public shareable URL.
